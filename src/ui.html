holder-kit local only

Runs on your own machine. Your password is sent to the local process and never saved, logged, or sent anywhere. Nothing on this page talks to the internet.

Vault password

Left as setup, chains and bench alone — those never touch a key. For testnet commands the CLI also wants the --i-know-this-is-testnet flag, which the buttons below add for you.

Get started

First time? Run Set up. It creates your vault and a wallet, then tells you what to do next. It also prints your password file location — move that somewhere safe.

RPC speed

Public RPCs rate-limit and stop long runs. Add two or three and bench shows which is fastest. Your key is saved to a gitignored file.

Wallets & backup

Back up the vault. Open the backup on another machine before you trust it — a backup never opened is a hypothesis, not a backup.

Find free mints

Mint it automatically spends real gas and needs gas in your wallets. Always run Find first and read the plan before using it.

Send NFTs to holders

Tokens are dealt round-robin to those addresses. Sends are recorded in a ledger, so re-running never double-sends.
